# Интеграция нового формата сезонов КВН на фронтенде

## Как это работает

### Автоматическое определение формата

Компонент `SectionDetailPage` автоматически определяет, какой формат показывать:

1. **Загружает данные** через API `/api/content/kvn/by-path/{path}`
2. **Проверяет наличие поля `season_data`** в ответе
3. **Если `season_data` есть** → показывает `SeasonDetailPage` (новый формат)
4. **Если `season_data` нет** → показывает старый формат (модули из `modules`)

### Структура компонентов

```
SectionDetailPage (роутер)
  ├── Если season_data есть → SeasonDetailPage
  │   ├── StageSection (для каждой стадии)
  │   │   └── GameTable (для каждой игры)
  │   └── Метаданные (победители, команды, жюри)
  └── Если season_data нет → Старый формат (ModuleList)
```

## Компоненты

### SeasonDetailPage
Главная страница сезона в новом формате.

**Расположение:** `frontend/src/public/pages/SeasonDetailPage.jsx`

**Отображает:**
- Заголовок с навигацией (предыдущий/следующий сезон)
- Постер сезона
- Теги команд-участников
- Метаданные (редакторы, ведущий, жюри)
- Победители сезона
- Список всех команд-участников
- Стадии сезона (через StageSection)

### StageSection
Компонент для отображения одной стадии (1/8, 1/4, 1/2, финал).

**Расположение:** `frontend/src/public/components/StageSection.jsx`

**Отображает:**
- Название стадии
- Все игры стадии (через GameTable)
- Информацию о доборе (если есть)

### GameTable
Компонент для отображения таблицы результатов одной игры.

**Расположение:** `frontend/src/public/components/GameTable.jsx`

**Отображает:**
- Название игры, дату, ведущего, жюри
- Таблицу результатов:
  - Место команды
  - Название команды (ссылка на страницу команды)
  - Баллы по каждому конкурсу
  - Итоговый балл
  - Статус (прошла/не прошла, победитель)

## API

### Endpoint
```
GET /api/content/kvn/by-path/{path}
```

**Пример:**
```
GET /api/content/kvn/by-path/kvn/premier-liga/2023
```

**Ответ:**
```json
{
  "id": "...",
  "title": "Сезон 2023 Премьер-лиги КВН",
  "full_path": "kvn/premier-liga/2023",
  "season_data": {
    "league_slug": "premier-liga",
    "year": 2023,
    "stages": [...],
    "winners": [...],
    "all_teams": [...],
    ...
  },
  "poster": {...},
  "tags": [...],
  ...
}
```

## Миграция

### Текущее состояние

- ✅ Новый формат работает параллельно со старым
- ✅ Автоматическое определение формата
- ✅ Старые сезоны продолжают работать в старом формате

### Следующие шаги

1. **Обработать все сезоны:**
   ```bash
   python migration/kvn/process_seasons.py --all --apply
   ```

2. **Проверить результаты:**
   ```bash
   python migration/kvn/get_seasons.py --count-only
   ```

3. **После проверки всех сезонов** можно:
   - Удалить старый формат отображения из `SectionDetailPage`
   - Или оставить fallback для сезонов без `season_data`

## Тестирование

### Проверка нового формата

1. Откройте сезон с обработанными данными:
   ```
   http://localhost:3000/kvn/premier-liga/2023
   ```

2. Должны отображаться:
   - ✅ Навигация между сезонами
   - ✅ Таблицы результатов игр
   - ✅ Стадии сезона
   - ✅ Победители
   - ✅ Команды-участники

### Проверка старого формата

1. Откройте сезон без `season_data`:
   ```
   http://localhost:3000/kvn/vl-kvn/vl-2022
   ```

2. Должен отображаться старый формат (модули из `modules`)

## Известные ограничения

1. **Ссылки на команды** - если `team_slug` не определён, ссылка не работает
2. **Навигация по сезонам** - пока не реализована (только prev/next)
3. **Оглавление сезонов лиги** - пока не реализовано

## Расширение

### Добавление новых полей

Если в `season_data` появятся новые поля:

1. Обновите `SeasonDetailPage.jsx` для отображения
2. Обновите типы данных (если используете TypeScript)
3. Обновите документацию

### Кастомизация стилей

Все компоненты используют Tailwind CSS и компоненты из `@/components/ui/`.

Для изменения стилей:
- Таблицы: `GameTable.jsx`
- Стадии: `StageSection.jsx`
- Общий вид: `SeasonDetailPage.jsx`
