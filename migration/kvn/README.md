# Импорт страниц КВН

## Импорт корневой страницы КВН (id=32)

Корневая страница КВН импортируется отдельно, так как она является родительским ресурсом для всех дочерних страниц.

```bash
# Dry-run (проверка без сохранения)
python migration\universal_importer.py --type kvn --ids 32 --verbose

# Импорт корневой страницы
python migration\universal_importer.py --type kvn --ids 32 --apply
```

После импорта корневая страница будет доступна в админке по адресу `/admin/kvn`.

## Импорт дочерних страниц

После импорта корневой страницы можно импортировать все дочерние страницы:

```bash
# Импорт всех дочерних страниц (parent=32) пакетами по 25 штук
python migration\universal_importer.py --type kvn --parent-id 32 --batch-size 25 --apply
```

## Импорт конкретной дочерней страницы

Если нужно импортировать конкретную дочернюю страницу с указанием родителя:

```bash
# По old_id родителя (из MODX)
python migration\universal_importer.py --type kvn --ids 123 --parent-old-id 32 --apply

# По slug родителя (из MongoDB)
python migration\universal_importer.py --type kvn --ids 123 --parent-slug kvn-root --apply
```

## Создание страниц вручную через админку

1. Перейдите в раздел **КВН** в админке
2. Нажмите **Добавить**
3. Заполните основные поля
4. В поле **Родительская страница** выберите:
   - **Корневая страница (без родителя)** - для страниц верхнего уровня
   - Или выберите существующую страницу КВН - для дочерних страниц
5. Сохраните

## Структура иерархии

КВН поддерживает иерархию до 4 уровней:
- Уровень 0: Корневая страница (например, "КВН")
- Уровень 1: Лиги, сезоны (например, "Высшая лига")
- Уровень 2: Конкретные сезоны (например, "Сезон 2024")
- Уровень 3: Игры, этапы
- Уровень 4: Конкретные игры

## Примечания

- Корневая страница должна быть импортирована первой
- При импорте дочерних страниц автоматически устанавливаются:
  - `parent_id` - ссылка на родительский документ
  - `full_path` - полный путь (например: `kvn/vysshaya-liga/season-2024`)
  - `level` - уровень вложенности
- Максимальный уровень вложенности: 4
