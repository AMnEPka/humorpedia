# Карточки основного состава четырёх шоу

Состояние на 2026-09-25: исходный `main` на `7eaf309`; отдельная ветка
`codex/show-core-cards`. В общем checkout есть параллельные незакоммиченные изменения,
которые не входят в эту ветку.

`backend/scripts/populate_core_show_cards.py` добавляет по одному модулю `participants`
после вступления в Comedy Club, «Женский стендап», Stand Up на ТНТ и «Убойную лигу».
По умолчанию dry-run, запись — `docker compose exec -T backend python
scripts/populate_core_show_cards.py --apply`. Повторный запуск заменяет только модуль
со своим ID; чужой модуль карточек блокирует запись.

Отбор: 15 резидентов Comedy Club разных лет по странице Comedy Club Production и локальному
списку; 15 комиков «Женского стендапа» с 12+ выходами в таблицах 1–6 сезонов;
20 комиков Stand Up с 20+ выходами в таблицах 1–11 сезонов (12-й имеет неполные числа);
32 человека из 20 сольных номеров и дуэтов «Убойной лиги» с 10+ выступлениями
по сводной таблице. В дуэтах победы и выступления подписаны как результаты дуэта.
Фото берутся только из существующих профилей Humorpedia; новые внешние изображения
не копируются. Источники отбора — в docstring скрипта.

Проверено: `tests/test_show_appearances.py` — 21 passed; публичный API выдаёт
15/15/20/32 карточки, из них 13/15/20/19 с профилями и фото; все 62 уникальных
URL фото ответили HTTP 200. В браузере проверен блок Comedy Club. Профилей нет
у двух резидентов Comedy Club и 13 участников «Убойной лиги»; их имена и факты
есть на карточках, ссылки и фотографии пока не добавлены.

При визуальной проверке остальных страниц CRA временно показывал ошибку импорта
`EditorialProposalsPage` из параллельной правки `frontend/src/App.js`. API четырёх
страниц проверен после записи.
