# Задача: восстановление квизов из MODX

Обновлено: 2026-09-18.
Область: backend-импорт и media-volume, модели/роуты квизов, публичные список/прохождение, локальная MongoDB.
Основание: ветка `codex/restore-quizzes`, база `origin/main` @ `aa648b4`.
Статус: реализовано, импортировано и проверено; коммит опубликован, открыт PR #31.

## Результат и границы

Восстановить опубликованный раздел квизов из `backups/idemsku8_modx2.sql`: карточки, обложки, вопросы, варианты,
правильные ответы, итоговые диапазоны, пояснения и старые URL. Черновик не публиковать.

## Решения

- Перенесены 11 опубликованных ресурсов и 160 вопросов. Незавершённый `Humorquiz #5` (`old_id=3150`, 6 вопросов) оставлен в дампе.
- Общие диапазоны `quiz_final` родительского раздела используются как fallback; верхняя граница ограничивается числом вопросов,
  недостижимые диапазоны отбрасываются.
- `text_success` и `text_error` сохранены отдельно, потому что одно общее `explanation` теряло поведение старого квиза.
- Две отсутствовавшие обложки восстановлены: одна из локального архива, одна со старого домена; обе проверены как изображения.
