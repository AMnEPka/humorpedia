## Пакет и повторный запуск

Пакет: `content/zvezdy-season3-2026.json`. Импортёр: `backend/scripts/update_zvezdy_season3.py`.

```powershell
docker compose cp .\content\zvezdy-season3-2026.json backend:/tmp/zvezdy-season3-2026.json
docker compose exec -T backend python scripts/update_zvezdy_season3.py /tmp/zvezdy-season3-2026.json
docker compose exec -T backend python scripts/update_zvezdy_season3.py /tmp/zvezdy-season3-2026.json --apply --backup-dir /app/backups/zvezdy-season3-2026
```

По умолчанию dry-run. Проверяются суммы и ранги жюри, полный список конкурсных команд,
восемь прошедших команд и соответствие жеребьёвки. Хеши пяти исходных блоков защищают
исследованный текст от перезаписи параллельных правок; изменение добавленных блоков также останавливает импорт.
Новые команды создаются обычным CRUD с уникальными тегами вида «Друзья (Звёзды на НТВ)».
Предварительная проверка всех новых тегов выполняется до первой записи.
Для обновляемых документов проверяются прежние поля и `updated_at`, после записи сбрасывается кэш всех воркеров.

Успешный импорт сохраняет отпечаток пакета в `season_research_import`:
повторный запуск того же пакета ничего не меняет и сохраняет последующие ручные правки.
Другое содержимое пакета требует нового исследования и отдельной проверки;
удалять отметку импорта для принудительной перезаписи нельзя.

Сохранение нескольких документов не является общей транзакцией. Первый запуск остановился на занятом
базовом теге «Друзья» после обновления трёх старых карточек. После уточнения тегов импорт продолжен,
дубли не созданы. Резервная копия первоначального состояния:
`backups/zvezdy-season3-2026/20261001T112333933952Z/before.json`.
Копия перед успешным продолжением:
`backups/zvezdy-season3-2026/20261001T112443801697Z/before.json`.
В контейнере эти пути начинаются с `/app/backups/`; каталог исключён из Git.
