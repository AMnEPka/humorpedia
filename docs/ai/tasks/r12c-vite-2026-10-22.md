## Диагностика dev

По ответу пользователя 22.10.2026: сохранить URL/HTTP-статусы, JSON обновить под Vite. Диагностика по-прежнему отключена по умолчанию и не входит в production nginx.

| GET URL | HTTP и новое содержимое |
|---|---|
| /health | 200, status/timestamp/uptime и vite: listening, ready, totalTransforms, lastSuccessfulTransformAt, errorCount/state |
| /health/simple | 200 IDLE или OK; 503 ERROR при известной ошибке |
| /health/ready | 503 до первой наблюдённой трансформации или при ошибке; 200 после трансформации при listening и без ошибок |
| /health/live | 200, alive/timestamp |
| /health/errors | 200, errorCount и errors: moduleId/message |
| /health/stats | 200, totalTransforms, lastSuccessfulTransformAt, serverUptimeSeconds, listening |

Vite обрабатывает модули по запросу, поэтому ready не доказывает полную компиляцию всего графа. Учитываются наблюдённые трансформации и ошибки из dev error channel; успешная повторная трансформация снимает ошибку именно своего moduleId. Ошибка без moduleId сохраняется до перезапуска сервера. Webpack compile times/hash/warnings/memory и фиктивный COMPILING не эмулируются. Потребителям прежнего JSON надо перейти на указанные поля.
