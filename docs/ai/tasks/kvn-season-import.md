# Импорт новых сезонов КВН

Обновлено: 2026-10-01, Москва. Ветка: `codex/kvn-season-import`, HEAD до изменений `a0da692`.
Статус: выполнено и проверено локально; результаты готовятся к commit/push в указанную ветку.

## Результат

Ручной редакционный импорт нового сезона из проверенного JSON с предпросмотром в **КВН → Импорт сезона**.
Существующие команды связываются, отсутствующие получают такой же пустой шаблон, как при импорте списком.
После создания сезон и игры доступны в обычном KVNEditPage/SeasonDataEditor. Изменение существующего
сезона другим пакетом намеренно не входит в этот механизм; редактор позволяет внести новые игры вручную.

Авторизация пользователя: создать сезон Высшей лиги 2026, команды и все опубликованные результаты;
commit/push в отдельную ветку ранее разрешены. Исследование Первой/Премьер-лиги — следующий этап,
ссылки на конкретные Telegram-каналы пока не предоставлены.

## Код

- `backend/models/season_import.py`: строгий пакет, ключи/алиасы команд, даты, баллы и итог.
- `backend/services/season_import.py`: preview, разрешение команд, аренда MongoDB для исключения
  параллельных импортов, штатный bulk-create и KVN CRUD, повторный импорт без дублей.
- `backend/routes/competitions.py`: две POST ручки импорта, editor/admin.
- `backend/models/content.py`, `backend/routes/content_kvn.py`: создание страницы сразу с `season_data`.
- `frontend/src/admin/components/SeasonImportDialog.jsx`, KVNListPage: JSON/файл, предпросмотр,
  связи и карточки новых команд, раскрываемые результаты игр, открытие готового редактора.
- `frontend/src/public/utils/seasonParticipant.js`, SeasonDetailPage: исторические имена и города.
- `backend/scripts/import_kvn_season.py`: CLI, без `--apply` не пишет в базу.

Контракт API и доменные правила — [COMPETITIONS.md](../COMPETITIONS.md).

## Высшая лига 2026 — локальная база

Источник: [Wikipedia](https://ru.wikipedia.org/wiki/Высшая_лига_КВН_2026), срез 2026-10-01;
редакция статьи, прочитанная при подготовке — 17 сентября. Пакет: `content/kvn-vl-2026.json`.

- Создана опубликованная страница `/kvn/vl-kvn/vl-2026`: `id=0c883bd5-4139-4ca6-be48-931316d00771`,
  `_id=9d8d76ad-e318-412f-88d4-1f34145cc6a8`. У KVN `id` и `_id` различаются.
- 20 участников, 4 игры 1/8, 4 четвертьфинала, 3 полуфинала, 45 строк результатов.
- Создана только «Не беспокоить», `teams._id=9c4184db-5e64-4876-ab0d-e896676aa23c`,
  slug `ne-bespokoit`, город Балашиха. Остальные 19 команд связаны с существующими карточками.
- НК ссылается на «Не кипишуй», Титаны — на «Негоден», Сборная РУДН — на «Сборная РУДН (Ренаты)».
  СПИКЛ/Мытищи и Error 404/Москва сохраняют прежние ссылки; города карточек не менялись.
- В третьей 1/8 два третьих места, ИнДа — четвёртое по опубликованному списку.
  В третьем четвертьфинале два вторых места: проход Леон Киллера после дополнительной разминки.
  Доборы «Сделано на Сахалине» в полуфинал и Леон Киллера в финал отмечены.
- Для второго полуфинала известны только суммы; `scores={}`, не нули.
  У первого полуфинала Wikipedia даёт 22,6/22,6/23,1, доступная Telegram-публикация —
  22,5/22,7/23,1 при тех же конкурсных баллах. Сохранены суммы указанной пользователем статьи,
  расхождение явно описано в notes. Жюри/эфир полуфиналов и неподтверждённые прямые проходы
  не добавлены. Пустой `winners`: чемпион ещё не указан, вымышленного финала нет.
- Telegram: публичные `t.me/s/kvninfo` и `t.me/s/craftysound1?before=15707` удалось прочитать;
  отдельные прямые ссылки недоступны веб-инструменту. Доступ к закрытым каналам не проверялся.
