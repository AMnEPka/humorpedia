# Открытые вопросы и недостающие данные

## Общие

1. **Backend API доступность** — для импорта необходимо, чтобы backend был запущен (`http://127.0.0.1:8000`). Скрипт `import_kvn_content.py` работает через REST API.

2. **Главная страница КВН (kvn)** — документ с `full_path: "kvn"` уже существует в MongoDB (импортирован ранее из MODX). При обновлении скрипт перезапишет содержимое модулей. Нужно решить: полностью заменять старый контент или дополнять.

3. **Действующие чемпионы лиг** — в Markdown указано «определяется автоматически». На сайте чемпион отображается из `season_data.winners` последнего завершённого сезона. Для центральных лиг пока нет `season_data` — нужно либо добавить модуль `league_champions` для них, либо заполнить `season_data` для каждого сезона.

4. **SEO мета-описание** — прописано в frontmatter каждого файла. Бэкенд поддерживает поле `seo` в KVN-документе, но текущий скрипт передаёт его только если оно есть в модели `KVNCreate`. Нужно проверить, что поле `seo` сохраняется при создании.

- Контент написан на основе общих знаний. Было бы хорошо добавить:
  - Статистику (точное число команд в Высшей/Премьер-лиге по годам)

  - Инфографику «от студенческой лиги до Высшей»

### Раздел «История КВН»

- Объём ~1500 слов (в рамках требований 1200–2000)
- Возможно стоит дополнить:
  - Подробности о советском периоде (1961–1971) — имена первых чемпионов
  - Детали о роли цензуры в закрытии КВН в 1971
  - Более подробно о 2020-х: смена руководства, новые форматы

- Раздел «Спецпроекты КВН» (`specproekt`, ID=1500) в MODX помечен как неопубликованный — нужно решить, публиковать ли отдельную страницу

## Технические вопросы

1. **Модуль `league_champions` для центральных лиг** — сейчас `LeagueChampionsBlock` поддерживает только `1l-kvn` и `vl-kvn`. Нужно расширить компонент `SectionDetailPage.jsx`, чтобы он:
   - Определял центральные лиги по `full_path` (начинается с `kvn/league/`)
   - Поддерживал рендеринг таблицы чемпионов для центральных лиг

2. **Роутинг центральных лиг** — текущий catch-all `SectionDetailPage` попытается загрузить `kvn/league/lampa` через API `getKvnByPath`. Если документ существует в MongoDB с правильным `full_path`, страница должна отобразиться. Нужно проверить.

3. **Навигация** — главная страница КВН `/kvn/` сейчас рендерится как `SectionDetailPage` с модулями и подразделами. При обновлении контента нужно убедиться, что оглавление с якорями работает внутри text_block модулей (сейчас якоря могут не поддерживаться ModuleRenderer).

4. **Страница «Центральные лиги»** — `kvn/league` уже есть в SQL (ID=1503). Нужно проверить, импортирован ли этот документ в MongoDB, и обновить его содержимое.
